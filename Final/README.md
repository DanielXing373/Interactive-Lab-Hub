## 3. 到货后要量的尺寸

在 `bwave_parts.scad` 顶部，标了【量】的参数：

**摆动舵机 DS3218**：耳朵下表面高度 `SW_TAB_Z`、含耳朵总长 `SW_TAB_L`、两端耳朵孔距 `SW_HOLE_DX`、同一耳朵两孔距 `SW_HOLE_DY`、输出轴离机身近端 `SW_SHAFT`、舵盘顶面高出顶盖 `HORN_TOP`、舵盘外径 `HORN_D`。

**翻牌舵机 MG90S**：机身厚 `FL_T`（最关键，决定层间距）、机身高 `FL_H`、输出轴离近端 `FL_SHAFT`、耳朵下表面离顶盖 `FL_TAB_FROM_TOP`、含耳朵总长 `FL_TAB_SPAN`、耳朵孔距 `FL_HOLE_DX`、舵盘顶面高出顶盖 `FL_ABOVE`。

**牌**：厚度 `CARD_T`。

量完后重新跑碰撞检查和导出，再打第 2 项。

## 5. 待办和注意事项

- [ ] Servo pHAT 与 Pi 分开供电：需要切断板上的隔离跳线，动手前先核对 SparkFun 官方 hookup guide。
- [ ] 充电宝实测：连续开机 30 分钟，看会不会自动断电。
- [ ] 白板散开的角度要重新调：当前是模拟器的旧默认值（当时按结局牌在最后一张设的），第 4 阶段有白板挡住结局牌。
- [ ] 结局牌移出角度（当前 40°）待调。
- [ ] 胶水：不要粘在输出轴和舵盘附近（胶渗进去会卡死），舵机机身尽量别粘死（坏了要换）。舵机附带的小螺丝能用就用。
- [ ] 交互方式待定。
